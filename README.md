PvPChecks плагин ограничивает предметы, снаряды и баффы в PvP, запрещая их или убирая регистрацию урона.
Предметы в бан добавляются:
 /banitem <add/del> <item name/ID> <prefix name/ID> <frozen:true/false> - Запретить предмет в пвп, где prefix и frozen устанавливаются только для оружия.
Для запрета аксессуаров и брони, указывать их не нужно. Если для оружия не указывать prefix и frozen, то prefix = 0 (без зачарования) и frozen = false (без заморозки, т.е. обнуление урона).
 /banproj <add/del> <projectile_ID> <frozen:true/false> - Запретить снаряд. Если не указывать frozen, то frozen = false (обнуление урона снаряда).
 /banbuff <add/del> <buff name/ID> - Запретить использование баффа в PVP.

Дополнительно, плагин запрещает дубликаты аксессуаров, переключение loadout (сетов) и исходя настроек в конфиге следующие параметры:
1. "portalGunBlock": - Запрет на использование портальной пушки
2. "solarArmorDebuff": - Ограничение брони солнечной вспышки (дебафф на уполовинивание брони)
3. "disabledcommandsInPvp": - Список запрещенных для использования команд во время PvP
